# Responsive Portfolio Website

This is a simple and clean responsive portfolio website built using HTML and CSS. It is designed to work smoothly on all screen sizes, including mobile, tablet, and desktop.

## About the Project

I built this project to practice my front-end development skills and understand how responsive layouts work in real-world websites. The design is kept minimal, easy to navigate, and user-friendly.

## Features

- Fully responsive design for all devices  
- Simple and clean layout  
- Navigation bar for easy browsing  
- Smooth structure for better user experience  
- Lightweight and fast loading  

## Built With

- HTML5  
- CSS3  

## What I Learned

- How to create a responsive layout using CSS  
- How to design and structure a navigation bar  
- How to organize a simple portfolio project
